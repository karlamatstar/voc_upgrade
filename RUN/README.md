# RUN — QA 런처 GUI

터미널 7개를 여는 대신, 한 창에서 서버 6개 로그와 테스트 실행을 모두 처리하는 GUI입니다.

## 실행

`VOC_QA_Launcher.bat` 더블클릭 — 또는:

```powershell
d:\voc\.venv\Scripts\python.exe d:\voc\RUN\run_gui.py
```

## 화면 구성

```
┌──────────────────────┬───────────────┬───────────────┬───────────────┐
│  ▶ 실행 터미널        │ Interpreter   │ Retriever     │ Summarizer    │
│  (테스트/LLM Judge)   │ :6001  ▶ ■   │ :6002  ▶ ■   │ :6003  ▶ ■   │
│                      ├───────────────┼───────────────┼───────────────┤
│  [전체 테스트]        │ Evaluator     │ Critic        │ Improver      │
│  [LLM Judge] [중지]   │ :6004  ▶ ■   │ :6005  ▶ ■   │ :6006  ▶ ■   │
└──────────────────────┴───────────────┴───────────────┴───────────────┘
상단: [▶ 전체 시작] [■ 전체 종료] [📂 보고서 폴더]
```

## 사용 순서

1. 상단 **[▶ 전체 시작]** — 에이전트 6개가 켜지고, 각 패널의 ●가 **초록**이 되면 준비 완료
   (● 회색=꺼짐, 노랑=기동 중, 초록=포트 개방)
2. 왼쪽 **[🧪 전체 테스트]** — pytest 결과가 실행 터미널에 색상으로 표시
   (초록=PASSED, 빨강=FAILED, 노랑=SKIPPED)
3. **[⚖ LLM Judge 실행]** — 채점 후 보고서 저장 → **[📂 보고서 폴더]**에서 확인
4. 창을 닫으면 실행 중인 서버·테스트가 모두 자동 종료됩니다

## 주의

- 에이전트는 `OPENAI_API_KEY` / `ANTHROPIC_API_KEY`가 등록되어 있어야 정상 기동합니다.
  키가 없으면 각 패널에 "client is not configured" 오류가 표시되고 종료됩니다.
  `setx`로 등록한 뒤에는 **런처를 새로 실행**해야 반영됩니다.
- 서버 없이도 [단위 테스트만] 버튼은 항상 동작합니다.
