## 4. TC-14 문제 조치와 재확인

처음 실행에서 TC-14의 질문인 `서비스가 별로예요.`가 검색 0건으로 처리되는 문제가 발견됐다. `서비스`를 항상 제거하는 방식 대신, 구체적인 검색어가 없는 모호한 질문에서만 `서비스`를 최소 검색 기준으로 사용하도록 Retriever를 보완했다.

보완 후 전체 실행을 처음부터 다시 수행했으며 TC-14는 네 실험군에서 모두 검색·채점됐다.

| 실험군 | TC-14 점수 | API 상태 |
|---|---:|---|
| A | 45.0 | 성공 |
| B | 20.0 | 성공 |
| C | 52.0 | 성공 |
| D | 49.0 | 성공 |

낮은 점수는 검색 실패가 아니라 질문 자체가 모호하고 활용 가능한 VOC 근거가 제한적인 상황에서 나온 평가 결과다. 따라서 이 결과는 모델 성능만의 문제라기보다 질문 구체성, 검색 근거, 데이터 범위의 영향을 함께 보여준다.

## 5. 결과 해석

이번 1회 실행에서는 A가 평균점수 75.1점으로 가장 높았고, C가 중앙 수행시간 20.75초로 가장 빨랐다. 빠른 반복 확인에는 C가 유리하고, 생성 모델과 평가 모델을 분리해 결과를 확인하는 최종 교차검증에는 A가 상대적으로 적합했다.

다만 테스트 케이스별 점수 차이가 크기 때문에 특정 모델이 절대적으로 우수하다고 단정하기는 어렵다. 특히 모호한 질문과 VOC 데이터 범위가 부족한 사례에서는 모델 조합보다 검색 결과와 근거 데이터가 점수에 더 큰 영향을 줄 수 있다. 발표에서는 모델 비교 결과와 함께 데이터 범위의 한계를 같이 설명하는 것이 자연스럽다.
