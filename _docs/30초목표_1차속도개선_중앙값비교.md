# 30초 목표 1차 속도 개선 및 중앙값 비교

- 작업일: 2026-07-16
- 대상: TC-01 단일 LLM Judge 실행
- 기준 실행: 파이프라인 33.49초, Judge 22.22초, 전체 55.71초
- 목표: 테스트 케이스 1건 전체 중앙값 30초 내외

## 1. 적용 내용

모델명은 바꾸지 않고 다음 저지연 설정을 추가했다.

- OpenAI: `reasoning_effort=none`, `verbosity=low`
- Interpreter 최대 출력: 300토큰
- OpenAI 공통 최대 출력: 900토큰
- Critic 최대 출력: 500토큰
- Anthropic 정책 생성: `effort=low`, `thinking=disabled`
- Anthropic Judge: `effort=low`, `thinking=disabled`
- Anthropic Judge의 4,096토큰 제한은 JSON 잘림 방지를 위해 유지
- Anthropic과 Judge 설정은 서로 독립적으로 조정할 수 있도록 분리

설정값은 `.env`로 변경할 수 있고, 사용 가능한 항목은 `.env.example`에도 추가했다.

## 2. 측정 중 확인된 제한 사항

Anthropic API는 세 회차 모두 다음 사유로 호출되지 않았다.

```text
HTTP 400 invalid_request_error
Your credit balance is too low to access the Anthropic API.
```

이는 `effort=low` 또는 `thinking=disabled`의 문법 오류가 아니라 Anthropic 계정의
크레딧 부족이다. 프로젝트의 기존 장애 처리 규칙에 따라 Anthropic 호출은 1회에서
재시도 불가 오류로 판정됐고 OpenAI 대체경로가 사용됐다.

따라서 아래 결과는 **Sonnet 5의 저추론 성능 측정값이 아니라 Anthropic 장애 시
OpenAI 대체경로 실측값**이다.

## 5. 기준값 비교와 해석

| 구간 | 기존 | 1차 중앙값 | 변화 |
|---|---:|---:|---:|
| 파이프라인 | 33.49초 | 25.52초 | 7.97초 단축 |
| Judge | 22.22초 | 5.17초 | 17.05초 단축 |
| 전체 | 55.71초 | 30.26초 | 25.45초 단축 |

전체 중앙값은 기존보다 약 45.7% 짧아졌으나 목표 30초보다 0.26초 길다. 세 회차 중
한 회차는 25.38초로 목표를 충족했다. 점수는 74점, 84점, 75점으로 편차가 있어
속도만으로 품질이 안정됐다고 판단할 수 없다.

특히 Judge 단축 폭의 대부분은 추론 강도 조정보다 Anthropic 실패 후 더 빠른 OpenAI
대체 모델을 사용한 영향이다. Anthropic 크레딧을 충전한 뒤 동일 설정으로 다시 3회
측정해야 Sonnet 5 저추론 설정의 실제 효과를 판단할 수 있다.
