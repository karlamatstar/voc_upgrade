# TC-14 모호한 서비스 질문 검색 보완

- 적용일: 2026-07-16
- 대상 질문: `서비스가 별로예요.`

## 발견된 문제

교차검증 A 실행에서 Interpreter는 `서비스 불만`을 추출했지만 Retriever의 검색
노이즈 목록에 `서비스`가 포함돼 있었고, `불만`, `별로예요`는 실제 VOC 문장과
일치하지 않았다. 그 결과 Retriever가 0건을 반환해 TC-14가 채점되지 않고 N/A로
처리됐다.

## 변경 내용

- `불만`, `별로`, `별로예요`를 검색 지시·감정 표현 노이즈로 분류했다.
- `서비스`는 평소처럼 범용 노이즈로 유지한다.
- 다만 구체적인 핵심어가 하나도 없는 모호한 질문에서는 `서비스` 하나만 최소 검색
  앵커로 사용한다.
- 구체어가 존재하는 일반 질문에서는 `서비스`를 검색 점수에 넣지 않아 기존 과다매칭
  방지 규칙을 유지한다.

이 방식은 TC-14에 여러 서비스 관련 VOC를 근거 후보로 제공하지만, 특정 원인을
정답으로 강제하지 않는다. 이후 Summarizer·Critic·Judge가 질문의 모호성과 추가 확인
필요성을 실제 결과에 반영했는지 평가할 수 있다.

## 검증

- 모호한 서비스 질문에서 서비스 관련 행만 검색되는 전용 단위 테스트 추가
- 기존 과다매칭·동의어·희소 단어·데이터 없음 검색 테스트와 함께 재검증
- 외부 LLM API를 사용하지 않는 검색 단위 테스트로 확인
