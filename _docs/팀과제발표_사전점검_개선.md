# 수강 과제·팀 발표용 사전 점검 개선 기록

## 작업 배경

이 프로젝트는 강사가 제공한 예시 코드를 기반으로 수강생이 기능과 품질을 개량하고,
다른 팀의 결과와 비교하여 발표하는 과제용 프로젝트다. 발표 직전에 환경 문제를 빠르게
발견하고, 팀원이 새 PC에서도 같은 패키지를 설치할 수 있도록 실행 준비 절차를 코드로
명확하게 만들었다.

> 보호 대상: `_docs/example_Don't touch` 폴더는 이번 작업에서 열거나 수정하지 않았다.

## 변경 내용

### 1. 프로젝트 의존성 선언

`pyproject.toml`에 실제 코드가 사용하는 패키지를 등록했다.

- 실행 패키지: OpenAI, Anthropic, gRPC, Protocol Buffers, MCP
- QA 선택 패키지: pytest
- `voc-preflight` 명령 등록
- pytest 기본 테스트 폴더를 `quality_diagnosis`로 지정

새 가상환경에서는 다음과 같이 설치할 수 있다.

```powershell
pip install -e ".[qa]"
```

### 2. 사전 점검 도구

`utils/preflight.py`를 추가했다. 이 도구는 외부 LLM API를 호출하지 않고 다음 항목만 확인한다.

- Python 3.13 이상인지 확인
- CSV, Proto 및 생성된 gRPC Python 파일 확인
- 필수 Python 패키지 설치 확인
- OpenAI 및 Anthropic API 키 설정 여부 확인
- 에이전트 6개의 로컬 포트 연결 가능 여부 확인

API 키는 실제 값을 출력하지 않고 `설정됨` 또는 `미설정`으로만 표시한다.
API 키와 에이전트 서버는 단위 테스트만 실행할 때 필수 조건이 아니므로 안내 항목으로 표시한다.

실행 방법:

```powershell
python -m utils.preflight
```

프로젝트를 설치한 경우 다음 명령도 사용할 수 있다.

```powershell
voc-preflight
```

## 발표 전 권장 순서

1. `python -m utils.preflight` 실행
2. 기본 파일과 패키지가 모두 `정상`인지 확인
3. API 키 두 개가 `설정됨`인지 확인
4. `RUN/VOC_QA_Launcher.bat`로 에이전트 6개 실행
5. 사전 점검을 다시 실행하여 6001~6006 포트 확인
6. 단위 테스트 또는 전체 파이프라인 시연

## 추가된 테스트

`quality_diagnosis/test_preflight.py`에서 다음을 검증한다.

- API 키의 실제 값이 보고서에 노출되지 않음
- 서버 미실행 상태가 기본 환경 점검 실패로 잘못 처리되지 않음
- 필수 파일 누락은 명확한 실패로 표시됨

## 2026-07-13 검증 결과

```text
Python 강제 컴파일: 성공
전체 pytest: 59 passed, 8 skipped
실패 테스트: 0
```

건너뛴 8개는 에이전트 서버 6개가 실행 중이어야 하는 통합 테스트다. 사전 점검 당시
필수 파일, Python 패키지, OpenAI API 키, Anthropic API 키는 모두 준비된 상태였고,
6001~6006 포트의 에이전트는 실행되지 않은 상태였다.

pytest 캐시 폴더 생성과 관련한 경고가 1개 있었지만 테스트 결과에는 영향을 주지 않았다.
